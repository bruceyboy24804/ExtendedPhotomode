# 1.2.0

A fix release.

- **Fixed a crash** when editing keyframes in the timeline. The same fault could also send an edit to the *wrong* curve without saying so — if a shot has drifted from what you set, this is why.
- **Undo and redo work.** They never have: both buttons were dead and always looked disabled.
- **Box select stays in one graph.** A box drawn in Position no longer drags Rotation and Focus along with it, and it now has a height, so you can grab the top half of a curve instead of a full slice of time.
- **Removed the orbit ring drawn over photo mode.** It appeared whatever you were shooting and could not be switched off without leaving photo mode. The ring you get while placing an orbit is unchanged.

Full details on [GitHub](https://github.com/bruceyboy24804/ExtendedPhotomode/blob/master/CHANGELOG.md).
