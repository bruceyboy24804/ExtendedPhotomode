# 1.2.0

Fixes, plus the first in-world controls for the path tool.

**Fixed**

- A crash when editing keyframes. The same fault could also edit the wrong curve without saying so.
- Undo and redo, which never worked.
- Box select now stays in one graph, and has a height.
- Keys are spaced evenly along a path instead of bunching through bends.
- Raising a path point can be undone, and takes the whole selection with it.
- The photo mode tab could hide the wrong sections.

**New**

- **Simple mode.** The panel keeps to shot type, subject, draw, duration and send, and the mod decides the rest. Turn on **Advanced** for every control.
- A button in the top-left toolbar opens the panel. Ctrl+P still works.
- Pick the shot type from a dropdown at the top of the path panel, before anything else.
- **To timeline editor** and **To cinematic camera** replace Generate, and confirm with a tick. The first also opens the timeline and shot list, so the shot lands where you can see it.
- Keyframes are drawn on the path.
- Drag handles for key spacing, bend density, point height, lens and orbit radius.
- The game's own elevation controls raise and lower points, snapping to round heights.

**Removed**

- The orbit ring drawn over photo mode. The one while placing an orbit is unchanged.

Full details on [GitHub](https://github.com/bruceyboy24804/ExtendedPhotomode/blob/master/CHANGELOG.md).
